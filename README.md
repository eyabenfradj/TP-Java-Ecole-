# TP-Java-Ecole-
TP Java POO - Classes, héritage et polymorphisme
## Description
Ce projet permet de gérer les personnes d'un établissement scolaire: étudiants et enseignants.
## Concepts utilisés
-Classes et objets
- Héritage (extends, super)
- Polymorphisme
- Classe abstraite
- Redéfinition des méthodes (@Override)
- ArrayList
## Classes
- Personne : classe abstraite.
- Etudiant : gestion des étudiants et calcul des moyennes.
- Enseignant : gestion des enseignants.
- Cours : gestion des cours et des étudiants inscrits.
- Main : exécution du programme.
## outil utilisé
IntelliJ IDEA - JDK27
